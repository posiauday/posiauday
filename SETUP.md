# Animated GitHub profile — setup notes

This is the special `posiauday/posiauday` repo: its README renders at the top of github.com/posiauday.

## What's here

| File | What it is | Regenerated by |
|---|---|---|
| `contrib-heatmap.svg` | Last 26 weeks of contributions plus past-year stats | Daily workflow |
| `whoami.svg` | ASCII portrait + neofetch card in one terminal window | `scripts/make_whoami_svg.py` (edit `ROWS`) |
| `card-*.svg` | Clickable project cards with live stars/forks | Daily workflow (`scripts/make_project_cards.py`) |
| `scripts/theme.py` | Shared colours, fonts and window chrome for every SVG | — |
| `preview.html` | Light + dark GitHub mock-up for local checks (git-ignored) | — |

The heatmap is refreshed daily (~06:17 UTC), on every push to `main`, and on demand from
**Actions → Update profile art → Run workflow**. If a run fails to push, set
Settings → Actions → General → Workflow permissions to **Read and write permissions**.

## Editing

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r scripts/requirements.txt

# whoami card: edit ROWS at the top of the script, then
python scripts/make_whoami_svg.py

# add or remove a project card: edit REPOS in scripts/make_project_cards.py

# new photo
python scripts/prep_photo.py my-photo.jpg     # transparent PNG works best; rembg used if installed
python scripts/make_whoami_svg.py             # INVERT=1 for the "ink" portrait look

# heatmap by hand (the workflow does this daily)
python scripts/fetch_contributions.py && python scripts/render_heatmap_svg.py
```

Any script accepts `STATIC=1` to output a frozen frame for previews.

## GitHub gotchas

- Inline `style=` is stripped from READMEs; only `<br>` gives vertical space.
- `<h1>`/`<h2>` add a full-width rule; the layout uses `<h3>`.
- No JavaScript. All motion lives inside the SVGs (SMIL + CSS keyframes), which GitHub plays in `<img>`.
- Every SVG is 860 wide and placed at `width="100%"`, so they line up and scale on phones.
- Tables draw cell borders you can't style away, so the layout avoids them; images inside `<a>` stay clickable.
